# `.github`

### The AxonOS organisation's community-health repository.

</div>

---

This repository is the AxonOS organisation's special `.github`
repository. It carries the files that apply across **every** repository
in the [AxonOS organisation](https://github.com/AxonOS-org) — chiefly
the organisation landing page rendered at
**[github.com/AxonOS-org](https://github.com/AxonOS-org)**.

It is not where the project lives. It is where the project's public
front door is wired up.

## What lives here

| Path | Purpose |
|:---|:---|
| [`profile/README.md`](./profile/README.md) | The organisation landing page (English) |
| [`profile/README.*.md`](./profile/) | The same landing page in seven additional languages |
| [`profile/banner.jpg`](./profile/banner.jpg), [`profile/logo.png`](./profile/logo.png) | Imagery used by the landing page |
